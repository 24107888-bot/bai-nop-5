BÀI CSS GRID & FLEX — THẾ GIỚI ĐỘNG VẬT

Tệp gồm 3 trang HTML, CSS dùng chung và ảnh SVG trong thư mục images.
- Liên kết “Chuyển đến Nội dung chính” trên mỗi trang trỏ tới #main-content.
- Nav rộng 80%, dùng Flexbox và ảnh biểu tượng khoảng 10%.
- CSS Grid có hai cột rộng 40%, cùng justify-content, align-items và row-gap.
- Ảnh trong Grid rộng 100%.
- Gallery riêng dùng Flexbox, flex-wrap và justify-content.
- Có media query cho màn hình hẹp.

Trước khi nộp: mở index.html, thử mọi liên kết, kiểm tra bằng https://wave.webaim.org/ và https://validator.w3.org/.
